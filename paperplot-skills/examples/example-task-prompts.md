# Example Task Prompts

Use these prompts as examples of appropriate `paperplot-skills` tasks.

1. Create a publication-ready boxplot from `data.csv`, comparing `condition` on the x-axis and `response` on the y-axis. Export PDF and PNG without overwriting old files.

2. Refine this existing ggplot2 figure into a manuscript-ready figure. First diagnose the current figure, then create a new versioned output stem.

3. Create a 2x3 small-multiple figure for six genome quality metrics. Preserve original units and use a shared sample order.

4. Generate a PCA scatter plot from `pca_scores.csv` with PC1 and PC2 on the axes, group-based colors, explained variance labels, and a vector output.

5. Create a heatmap from long-form data with columns `feature`, `sample`, and `score`. Use a GraphPad-like gradient and label the colorbar with units.

6. Build a correlation scatter plot with `expression` on the x-axis and `phenotype` on the y-axis. Add a linear trend line and leave a placeholder for correlation statistics.

7. Create a grouped barplot with error bars from summary data. Use consistent colors and make sure category labels are readable.

8. Redraw this rough figure, but do not copy its bad layout. Diagnose hard issues first, then choose a clearer template.

9. Export a submission-ready figure as PDF and PNG. Use versioned file names and write notes with file sizes, design decisions, and QA checks.

10. Check whether this figure legend matches the panel labels and order in my multi-panel figure. Create a corrected version without overwriting the original.

# Main vs Supplement Density

Figure role determines information density.

## Main Figure

- Show the primary message quickly.
- Use selective labels.
- Use shared legends.
- Move lookup tables and full mappings to metadata or sidecars.
- Avoid panels that look like diagnostics.

## Supplement Figure

- Can show more labels and more panels.
- Still needs clear units, legends, and ordering.
- Can include full sample labels if space allows.

## Diagnostic Figure

- Prioritize complete inspection over aesthetics.
- Full labels and dense annotations are allowed.
- Must not be reported as manuscript-ready without redesign.

## Exploratory Figure

- Can be looser, but should record caveats and next design decisions.
